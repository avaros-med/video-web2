## Project Overview

Twilio Video web client (video-web2) — a React/TypeScript single-page application for video consultations. It connects to the schedule service for token generation and uses SSE (Server-Sent Events) for room event relay.

## Key Facts

- **Active branch**: `schedule-mysql`
- **Frontend URL**: served at `/av/video2` (REACT_APP_BASE_HREF)
- **Token endpoint**: `/av/api/schedule-mysql/video/token/` (schedule service, port 8810)
- **SSE endpoint**: `/av/api/schedule-mysql/video/sse/` (schedule service)
- **Dev server port**: 3002 (started via `start-dev.sh` in ark repo)
- Express server and Firebase auth have been removed — do not re-add them

## Running Locally

```bash
NODE_OPTIONS=--openssl-legacy-provider PORT=3002 npm start
```

Or via the ark repo's `start-dev.sh`.

## Testing

**IMPORTANT**: This project uses `ts-jest` with a `jest.config.js` directly — do NOT use `react-scripts test`.

```bash
# Run all tests
npm test

# Run specific tests
TZ=utc npx jest --testPathPattern="SomeComponent"

# CI mode with coverage
npm run test:ci
```

The `TZ=utc` flag is set by the test script to ensure consistent date handling across timezones.

## Building

```bash
npm run build
```

## Architecture

- **`src/state/`** — App state context, passcode auth hook, settings
- **`src/services/ws/socket.service.ts`** — SSE connection and outbound REST relay
- **`src/components/`** — UI components (Room, PreJoinScreens, VideoProvider, etc.)
- **`src/hooks/`** — Twilio video hooks (useVideoContext, useParticipants, etc.)
- **`public/virtualbackground/`** — Generated by postinstall from @twilio/video-processors

## Environment Variables

Copy `.env.example` to `.env` and fill in values. Key vars:

```
REACT_APP_BASE_HREF=/av/video2
REACT_APP_VIDEO_BASE_URL=/av/api/schedule-mysql/video
REACT_APP_SSE_URL=/av/api/schedule-mysql/video/sse/
REACT_APP_TOKEN_ENDPOINT=/av/api/schedule-mysql/video/token/
```
